## ✨ Features & Sections

- **Hero Section:** Introduction banner with call-to-action buttons (`About Me` and `View My Work`).
- **About Me Section:** Background overview, technical journey, and open-source experience.
- **Featured Projects:** Showcase cards featuring key web applications:
  1. **Speed Typing Game:** Interactive game built with HTML, CSS, and JS.
  2. **Personal Portfolio:** Fully responsive developer web layout.
  3. **Open Source Contributions:** Summary of open-source fixes and collaborations.
- **Contact Section:** Direct email CTA link (`mailto`) for project collaborations.
- **Responsive Navigation:** Accessible header navigation menu with toggle support and smooth anchor scrolling.
- **Social Integration:** Links to GitHub, X (Twitter), and LinkedIn profiles in the footer.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture, accessible landmarks, and proper `aria` attributes.
- **CSS3:** Custom styles and layouts (`website.css`, `linkcard.css`).
- **JavaScript:** Interactivity, menu toggles, and state handling (`script.js`).
